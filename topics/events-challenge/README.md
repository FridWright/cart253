# In-Class Events Challenge

Fridrikka Wright

## Description

Updated script of the "Only Move Is Not To Play" game from:
https://pippinbarr.com/cart253/assignments/challenges/events/
*Adds these parameters:*
Write a lose() function, make the user lose if they use the keyboard, and make the user lose if the use the mouse.
