# Prototyping - Arrays: The Resort

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-arrays/resort/)

## Description

24 people on holiday at a resort, user can press the spacebar to put the resort-goers into different vacation scenes to see how they will spend their time.
