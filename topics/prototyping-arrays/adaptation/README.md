# Prototyping - Arrays: Night Adaptation

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-arrays/nightadaptation/)

## Description

 * Night Adaptation is a prototype that illustrates the process of your eyes adjusting to the night sky over time. The longer you look at the night sky, the more stars appear. The user can reset the adjustment by hitting spacebar to blink.
