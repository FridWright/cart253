# Prototyping - Conditionals (Ghosts)

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-conditionals/ghosts/)

## Description

 10 ghosts charge at lamp -- to have them turn back, click the lamp to turn it on and illuminate them in a light beam (they will also turn red and close their eyes).
