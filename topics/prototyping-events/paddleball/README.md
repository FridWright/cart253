# Prototyping - Events: Paddleball

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-events/paddleball/)

## Description

A classic paddleball game where the user can play themselves (or another)
by moving the paddles on the L&R sides of the screen (with keys) to bounce a ball back and forth. A new ball is automatically added to the play every 10 seconds, and the game is over when there is no balls left in play.
