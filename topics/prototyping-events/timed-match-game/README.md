# Prototyping: Events - Timed Match Game

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-events/timed-match-game/)

## Description

This is a re-vamp of the "Match Game" created for the prior Prototyping- Conditionals assignment.
Introducing "Timed Match Game"... now with music!!
It is a card matching game where the user must find all matching colours (8 total).
This rework introduces a timer wherein all matches must be found before time runs out.
It also includes randomization of the card colours each reload, so the cards change their position for each new game. 
And now, if the user finds all matches before the timer runs out, they are congratulated and asked if they want to play again.
