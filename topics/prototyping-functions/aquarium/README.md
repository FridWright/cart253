# Prototyping - Functions: Aquarium

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-functions/aquarium/)

## Description

This prototype is a simulation of an aquarium where the user can watch 6 different colours of fish swim peacefully by. If the user presses the spacebar, a shark enters the screen making the fish swim faster until he's swam off screen.
