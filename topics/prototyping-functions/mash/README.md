Fridrikka Wright

## Description

M.A.S.H. is a prototype of the childhood game we maybe all know and love. In this version, the user spins the wheel, and their "future life" is revealed to them - at least in terms of marriage, house, job, salary, luck, and car. If they don't love it, they can always re-spin by hitting the space bar. Bonne chance!
