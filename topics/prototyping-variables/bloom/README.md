# Prototyping - Variables (Bloom)

Fridrikka Wright
[View this project online](https://fridwright.github.io/cart253/topics/prototyping-variables/bloom/)

## Description

This is a potted flower that grows taller and blooms when it's watered. Click on the pot multiple times to water the flower.
