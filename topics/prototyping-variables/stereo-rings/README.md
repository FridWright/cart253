# Prototyping - Variables (Stereo Rings)

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-variables/stereo-rings/)

## Description

This project is a expanding and contracting set of concentric circles with an outer "aura" ring. This aura ring slightly expands when the mouse is near it. Semi-stereo vibes.
