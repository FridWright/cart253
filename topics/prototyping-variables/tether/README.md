# Prototyping - Variables (Tether)

Fridrikka Wright

[View this project online](https://fridwright.github.io/cart253/topics/prototyping-variables/tether/)

## Description

An anchor point (mouse cursor) and attached tether line can pull a white circle around the screen. The circle is small and white when not in motion, and inflates and turns purple when dragged.
